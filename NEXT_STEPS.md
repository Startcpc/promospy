# После скачивания PromoSpy

1. Распакуйте ZIP полностью. Для Windows запустите `START_WINDOWS.cmd`. Для macOS или Linux выполните `python3 start.py` в папке проекта. При первом запуске нужны Python 3.9+ и интернет для установки зависимостей.
2. Откройте http://localhost:3000. Выберите магазин. В строку поиска можно ввести «бургер кинг», а кнопкой «Рестораны» показать все три сети.
3. Нажмите «Обновить». Раскройте условия найденного предложения и проверьте срок, город и тип заказа. Чтобы передать найденные предложения другу, откройте «Избранное» и экспортируйте сохранённые карточки.
4. Чтобы поделиться приложением, перешлите исходный ZIP или ссылку на GitHub. Личное избранное переносится отдельным файлом. Подготовленные зависимости устанавливаются на компьютере получателя.

Для обновления исходников и запуска на другом порту используйте [руководство по запуску](START_HERE.md). Для запуска в контейнере есть [инструкция Docker](docs/docker.md). Задача для дальнейшей разработки находится в [NEXT_AGENT_TASK.md](NEXT_AGENT_TASK.md).
