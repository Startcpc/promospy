# Что делать после скачивания PromoSpy 0.16.0

## Для тебя и друга

1. **Полностью распаковать ZIP.** В нём все исходники, логотипы, шрифты, lockfile, настройки, тесты и файлы запуска. Не запускайте лаунчер прямо из окна архиватора.
2. **Выбрать один способ запуска.** Python 3.9+: Windows — `START_WINDOWS.cmd`, macOS/Linux — `python3 start.py`. Либо с установленным Docker: `docker compose up -d --build --wait`. В первом варианте Node.js устанавливается автоматически. Интернет нужен для первой подготовки и поиска.
3. Открыть **http://localhost:3000** → **«Промокоды ВкусВилл» → «Обновить»**. Не закрывать терминал/контейнер, пока приложение нужно. Не запускать две копии на одном порту; при необходимости использовать `python3 start.py --port 3001`.
4. Если нужно перенести личные коды: в старом браузере открыть **«Избранное → Перенос избранного → Скачать файл»**, затем загрузить файл в новом браузере. ZIP проекта не содержит личного избранного.
5. Для обновления Git-клона остановить приложение, выполнить `git pull --ff-only origin main`, снова запустить лаунчер. Для Docker повторить команду сборки. Существующие данные не удалять.

Никаких ключей API, аккаунтов, базы данных или платной модели для обычного запуска настраивать не надо. Подробности: [START_HERE.md](START_HERE.md), [Docker](docs/docker.md), [сервер](docs/server-setup.md).

## Что сделано

- Полностью переработаны главная, карточки и стили поиска/избранного: крупный текст, удобные кнопки, адаптация к телефону, видимый фокус и переход к содержимому с клавиатуры.
- Добавлены фильтр официальных публикаций, сортировка по сроку и минимальному заказу, сброс фильтров, сумма и срок прямо на карточке.
- Исправлена потеря читаемого избранного при повреждённом обновлении localStorage другой вкладкой.
- Исправлено обрезание длинных условий при сохранении и переносе избранного.
- Исправлены старт страницы без сети и включение поиска после восстановления подключения. До первого нажатия поиск не запускается.
- Неполный ответ API вызывает повтор запроса. Добавлена страница восстановления после непредвиденной ошибки.
- Извлечение минимального заказа понимает дополнительные явные формулировки. Разные суммы для разных услуг не превращаются в одну придуманную сумму.
- Исправлен standalone-запуск ZIP, распакованного внутрь другого Node workspace; сборка проверяет наличие серверного файла.
- Исправлен перенос заголовка при отличающихся системных шрифтах.
- Next.js и его ESLint-конфигурация обновлены до 16.4.5: закрыты две обнаруженные уязвимости зависимостей.
- Удалены устаревшие дублирующие файлы передачи задач, старый отчёт релиза и неиспользуемая подсветка указателем. Инструкции больше не предлагают старый Docker-образ как текущую версию.
- Добавлена команда `pnpm package:zip`: архив всех файлов чистого коммита + SHA-256. Зависимости, сборка, кеш и секреты в него не попадают.
- Изменения отправлялись небольшими коммитами в `main`. Удалены ветки `fix/vkusvill-stabilization` и `feat/resilient-public-promo-discovery`, закрыт устаревший PR #1. Уникальный старый коммит доступен по тегу `archive/resilient-public-promo-discovery-2026-11-17`.

## Что остаётся за пределами этого архива

- **По желанию опубликовать Docker-образ 0.16.0.** В Docker Hub в рамках этой работы он не публиковался. Текущая версия запускается из исходников командой Compose выше. Старый тег 0.15.0 не содержит этих изменений.
- Для публичного сайта выбрать сервер, домен и HTTPS, настроить постоянный диск и резервные копии по [инструкции сервера](docs/server-setup.md). Это не требуется для локального запуска у друга.
- Нативный запуск на конкретном Windows/macOS проверить на компьютере получателя. Лаунчер имеет автоматические тесты; проверка Linux не заменяет запуск на каждой ОС.
- Доступность внешних источников проверять повторно при изменении их разметки. CAPTCHA и закрытые страницы не обходятся. Применение в реальной корзине пользователь проверяет со своими условиями заказа.

## Как снова собрать архив

В чистом Git-клоне с установленными зависимостями:

```sh
pnpm check
pnpm package:zip
```

Результат: `work/promospy-0.16.0.zip` и соседний `.sha256`. Архив соответствует одному коммиту. Внутри одна папка `promospy/`; Git для её запуска не нужен. Тяжёлые зависимости получатель устанавливает автоматически под свою платформу.
