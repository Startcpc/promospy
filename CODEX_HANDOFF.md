# PromoSpy — передача проекта следующему Codex

Состояние на 5 ноября 2026. Это существующий проект: продолжай его, сохраняя текущий интерфейс и рабочие механизмы.

## Что уже сделано

- Next.js / React / TypeScript, Prisma / SQLite. Каталог из 12 магазинов, поиск по промокодам, условиям и магазинам.
- Компактные карточки: заголовок и код; копирование без раскрытия, условия — по нажатию. Фильтр актуальных предложений.
- Общая серверная очередь: `PromoScanJob`, `PromoWorkerLease`; предложения и история — `PromoOffer`, `PromoCheck`. Обновление раз в час, повтор после ошибки через 15 минут, восстановление после перезапуска.
- **Автоматический сбор официальных публикаций ВкусВилла (ID 54) и Магнита (ID 201) работает.** Без авторизации и корзин. Два последовательных живых сбора, сохранение, повторное обновление и фоновый запуск сервером проверены. Источники: https://vkusvill.ru/promocodes/ и https://promo.magnit.ru/. На момент проверки — `1раз` (200 ₽ от 1000 ₽, первый заказ) и `ДОСТАВКА25` (25% от 1000 ₽, первый заказ). Новые коды извлекаются из разметки, не из жёстко заданного списка.
- Истёкшие/отклонённые предложения ниже в списке, через 24 часа скрываются; история остаётся в базе.
- Последняя проверка: 36 автоматических тестов прошли, ESLint для изменённых файлов и production-сборка прошли; карточки и поиск проверены браузерным тестом. Полный `pnpm lint` на всём старом репозитории в последнем этапе не запускался.

## Согласованные правила — сохранять

1. Статус `official` («На официальном сайте») означает публикацию кода на официальном источнике. Это не проверка применения к любой корзине. `verified` — отдельное подтверждение в конкретной тестовой корзине.
2. Официальный статус снимается при подтверждённом отсутствии в полностью прочитанном списке или указанном истечении срока. При исчезновении код становится `found` с пояснением.
3. Сетевая ошибка, 401/403, таймаут и изменение разметки **не доказывают исчезновение**. Сохранять статус и реальную дату последнего успешного чтения. Не добавлять срок жизни 6 часов для `official`: пользователь это явно отверг. Такой срок относится только к проверкам корзины.
4. Не выдумывать коды, даты, условия, регион и успешную проверку. Сохранять регистр: код `1раз` содержит кириллицу и строчные буквы.
5. Тануки исследуется только для Москвы. Применимость в Москве для кодов других магазинов автоматически не приписывалась.

## Тануки: ограничение, а не выполненная автоматизация

Отдельный адаптер есть, но в проверенном окружении QRATOR блокирует самостоятельный сбор: HTTP 401, выполнение проверочного JS, затем 403. Полный Chromium и прямое обращение к публичному API тоже не дали данных. В браузере приложения акции открывались. NEW20 и DR15 попали в базу после реального просмотра, а не полноценного автоматического сбора. Не объявлять задачу решённой и не тратить время на повторение тех же запросов. Нужен согласованный источник/доступ либо отдельное испытание на конкретном целевом сервере; успех переноса заранее неизвестен. Подробности: `docs/tanuki-collection-findings.md`.

## Быстрый старт после распаковки

Нужны Node.js 24+ и pnpm. Команды из корня:

```sh
pnpm install
# Скопировать .env.example в .env (Windows PowerShell: Copy-Item .env.example .env).
pnpm db:generate
pnpm exec playwright install chromium
pnpm dev
```

Открыть http://localhost:3000, магазины `/company/54` и `/company/201`. В архив включён согласованный снимок текущей SQLite-базы `db/custom.db`; для него `db:push` обычно не нужен. Если база создаётся заново, использовать `pnpm db:push`; не применять `db:reset` к заполненной базе. При изменении схемы сначала сделать резервную копию. Production: `pnpm build`, затем `pnpm start`.

```sh
pnpm test
pnpm build
pnpm test:smoke
# Живой сбор через общую очередь; worker должен быть свободен:
node --env-file=.env --import ./scripts/register-ts.mjs scripts/refresh-official.ts 54 201
```

`PROMO_WORKER_ENABLED=1` запускает фоновые задания вместе с долгоживущим сервером. Для отдельного worker отключить встроенный (`0`) и запустить `pnpm worker` с той же базой. Браузер посетителя может быть закрыт. Круглосуточный сбор требует постоянно работающего сервера; внешнего deployment пока нет. SQLite хранить на постоянном диске. На Linux Chromium может потребовать `pnpm exec playwright install --with-deps chromium`.

## Где работать

- `src/lib/public-official.ts` — адаптеры ВкусВилла/Магнита, ограниченная загрузка HTML и проверка разметки.
- `src/lib/scan-engine.ts` — выбор сборщика; ВкусВилл/Магнит идут по официальной ветке, без агрегаторов и проверки корзин.
- `src/lib/promo-worker.ts`, `src/instrumentation.ts` — очередь и запуск фонового процесса.
- `src/lib/promo-store.ts`, `src/lib/promocodes.ts` — хранение, статусы, поиск, сортировка и скрытие.
- `src/lib/tanuki-official.ts` — проблемный источник Тануки.
- `tests/public-official.test.ts`, `tests/fixtures/` — реальные фрагменты разметки и проверки полного цикла (ошибка, исчезновение, возвращение, повторный запуск).
- `docs/official-sources-audit.md` — результаты первичной проверки 11 остальных магазинов.
