# PromoSpy 0.8.0 — 06.11.2026

Требования владельца: обычный локальный запуск на macOS 12, Windows и Linux, без обязательного GitHub/Codespaces. При открытии магазина промокоды загружаются сами: сначала официальные акции, затем сторонние источники. API-ключей нет. Убраны буквенные заглушки и задержки нажатия.

Начать с README.md, START_HERE.md, docs/release-0.8.0.md и NEXT_AGENT_TASK.md. Для Mac: python3 start.py или START_MAC.command. Переносимый Node 22 LTS совместим с macOS 12; сторонние установщики и администратор не нужны. Для работы поиска нужен интернет к источникам.

Runtime: Next.js, React, cheerio, lucide-react, undici. SQLite сохранена как исторический снимок, сайт использует отдельный файловый кеш. Старые сборщики/корзины, примеры, массовые логотипы и UI-шаблоны удалены; полезные HTML-фикстуры перенесены в tests/fixtures.

41 unit-тест, 22 сценария поиска магазинов, браузерная приёмка. Прочитать отчёт для границ живой проверки: сеть этой среды ограничена. Не выдавать тестовые данные за найденные в интернете.
