# PromoSpy 0.12.0

Единственный активный магазин — ВкусВилл, ID 54, https://vkusvill.ru. Next.js/React/TypeScript сохранены. Прочитать README.md, NEXT_AGENT_TASK.md и docs/release-0.12.0.md; прежние release notes исторические.

Официальная страница и пять каталогов проверены настоящим HTTP 9 ноября 2026 года. URL и отключённые источники — src/lib/source-catalog.ts. Доступность нельзя переносить на другую дату или сеть. Найденный код не означает проверку в корзине.

Старый localStorage v1 не перезаписывается; активный список ВкусВилл использует отдельный v2-ключ. Кеш движка 7 сохраняет валидные результаты ВкусВилл. SQLite, Prisma и неактивные файлы данных не удалены. Восстановление старого смешанного backup активирует только ВкусВилл и сохраняет предыдущую папку.

Полная проверка: PROMO_TEST_CHROMIUM_EXECUTABLE=/usr/bin/chromium pnpm check. Живая диагностика: pnpm test:live 54; pnpm audit:sources 54. Сеть и browser-моки — разные проверки. Не переносить синтетические коды из tests в рабочие данные. Один Node-процесс; внешние ограничения не обходить, никаких обязательных ключей или платных сервисов.
