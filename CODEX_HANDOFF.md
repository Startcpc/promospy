# PromoSpy 0.9.0 — 07.11.2026

Требования владельца: обычный локальный запуск на macOS 12, Windows и Linux, без обязательного GitHub/Codespaces. При открытии магазина промокоды загружаются сами: сначала официальные акции, затем сторонние источники. API-ключей нет. Убраны буквенные заглушки и задержки нажатия.

Начать с README.md, START_HERE.md, docs/project-review-0.9.0.md и NEXT_AGENT_TASK.md. Для Mac: python3 start.py или START_MAC.command. Переносимый Node 22 LTS совместим с macOS 12; сторонние установщики и администратор не нужны. Для работы поиска нужен интернет к источникам.

Runtime: Next.js, React, cheerio, lucide-react, undici. SQLite сохранена как исторический снимок, сайт использует отдельный файловый кеш. Старые сборщики/корзины, примеры, массовые логотипы и UI-шаблоны удалены; полезные HTML-фикстуры перенесены в tests/fixtures.

104 unit-теста, 22 сценария поиска магазинов, 6 браузерных сценариев, 10 проверок загрузчика и 2 SQLite-проверки. Прочитать отчёт для границ живой проверки: сеть этой среды ограничена. Не выдавать тестовые данные за найденные в интернете.

Исправлены ложная блокировка по captcha-скрипту, скрытые окончания кодов, распознавание карточек и пустой кеш прежнего парсера. Сбой разбора не объявлять успешным отсутствием купонов. Реальные HTTP-проверки — pnpm test:live; сетевые моки остаются только в tests.

По требованию владельца выполнены пять проходов после первоначальных исправлений. Фактическая хронология — docs/audit-0.8.2-five-passes.md. Чистый запуск проверяется без Node/pnpm/сборки; повторный запуск и перенос папки также проверяются отдельно. Не заменять такой тест вручную выставленными отпечатками state.json.

Дополнительная проверка 0.9.0: docs/project-review-0.9.0.md. Исправлены обновление открытой страницы после TTL, повтор принудительного запроса, даты и сохранение официального подтверждения при сбое. Клиент больше не зависит от AbortSignal.any/timeout/throwIfAborted; браузерный сценарий отключает их явно. Это не заменяет физический тест Safari на Mac.

Версия 0.9.0: перенос избранного, пауза скрытой/offline-вкладки, расчёт TTL по времени сервера, backup/restore JSON-кеша через Python и pnpm, ежедневный systemd-таймер, GitHub Actions и pnpm check. CSS очищен до 67 строк. Резервирование не подменяет исторические SQLite-команды.
