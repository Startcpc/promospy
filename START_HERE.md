# Запуск PromoSpy

## Клонировать и запустить в VS Code

Один раз установите [Git](https://git-scm.com/downloads) для клонирования и [Python 3.9+](https://www.python.org/downloads/) для запуска. На Windows при установке Python включите **Add python.exe to PATH**. После установки перезапустите VS Code.

1. В VS Code нажмите **Ctrl+Shift+P** → **Git: Clone / Git: Клонировать**.
2. Вставьте `https://github.com/Startcpc/promospy.git`, выберите папку и нажмите **Открыть** после клонирования.
3. Нажмите **Ctrl+Shift+B** (Mac: **Cmd+Shift+B**). Запустится задача **PromoSpy: запустить**.

Зависимости установятся, сайт соберётся и откроется на **http://localhost:3000**. При первой подготовке дождитесь завершения установки и сборки в терминале. Для остановки нажмите **Ctrl+C** в этом терминале. Для повторного запуска снова нажмите **Ctrl+Shift+B**.

Если хотите редактировать сайт с автоматическим обновлением: меню **Терминал → Выполнить задачу → PromoSpy: редактировать сайт**. Перед этим остановите обычный запуск.

## Запуск командой или из ZIP

Также можно скачать ZIP, распаковать и открыть папку в VS Code.

На Mac и Linux в терминале:

```sh
python3 start.py
```

На Windows: `python start.py` или двойной клик по **START_WINDOWS.cmd**. На Mac также есть **START_MAC.command**.

Нужен Python 3.9+. Всё остальное подготовится автоматически при первом запуске, браузер откроется на **http://localhost:3000**. macOS 12 поддерживается выбранным Node 22 LTS. GitHub и Codespaces для работы сайта не нужны.

Откройте «Промокоды ВкусВилл» и нажмите «Обновить». До нажатия страница пустая; после него коды появляются по мере свежего чтения источников. Далее результаты обновляются каждые **5 минут**, даже при закрытой вкладке, пока сервер запущен. Остановить сайт: **Ctrl+C**.

Для первой подготовки и свежего поиска нужен интернет. Если порт занят: `python3 start.py --port 3001`. Для редактирования сайта: `python3 start.py --dev`.

Если используете Codespaces: выполните ту же команду и откройте порт **3000** в **Ports → Open in Browser**.

Избранное можно перенести через «Избранное → Перенос избранного». Скачайте файл и загрузите его в другом браузере.

Резервная копия результатов поиска: `python3 start.py --backup`. Для восстановления остановите сайт: `python3 start.py --restore "путь/к/копии.json"`. На Windows используйте `python` вместо `python3`. Если обычно запускаете с другим портом, передайте тот же `--port` при восстановлении.

## Обновление клона в VS Code

Остановите прежний сервер сочетанием Ctrl+C. В папке проекта:

```sh
git pull --ff-only origin main
python3 start.py
```

На Windows используйте `python`. Вместо команды запуска можно снова нажать **Ctrl+Shift+B**. Launcher сам пересоберёт изменённый проект. В «Подробнее об обновлении» появится актуальная версия. Просто скачанный коммит не заменяет уже работающий процесс.
