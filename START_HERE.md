# Запуск PromoSpy

Скачайте ZIP, распакуйте и откройте папку в VS Code.

На Mac и Linux в терминале:

```sh
python3 start.py
```

На Windows: `python start.py` или двойной клик по **START_WINDOWS.cmd**. На Mac также есть **START_MAC.command**.

Нужен Python 3.9+. Всё остальное подготовится автоматически при первом запуске, браузер откроется на **http://localhost:3000**. macOS 12 поддерживается выбранным Node 22 LTS. GitHub и Codespaces для работы сайта не нужны.

Выберите магазин — промокоды загрузятся сами. Остановить сайт: **Ctrl+C**.

Для первой подготовки и свежего поиска нужен интернет. Если порт занят: `python3 start.py --port 3001`. Для редактирования сайта: `python3 start.py --dev`.

Если используете Codespaces: выполните ту же команду и откройте порт **3000** в **Ports → Open in Browser**.

Избранное можно перенести через «Избранное → Перенос избранного». Скачайте файл и загрузите его в другом браузере.

Резервная копия результатов поиска: `python3 start.py --backup`. Для восстановления остановите сайт: `python3 start.py --restore "путь/к/копии.json"`. На Windows используйте `python` вместо `python3`. Если обычно запускаете с другим портом, передайте тот же `--port` при восстановлении.

## Обновление клона в VS Code

Остановите прежний сервер сочетанием Ctrl+C. В папке проекта:

```sh
git pull --ff-only origin main
python3 start.py
```

На Windows используйте `python`. Launcher сам пересоберёт изменённый проект. В «Подробнее об обновлении» должна появиться версия **0.10.3**. Просто скачанный коммит не заменяет уже работающий процесс.
