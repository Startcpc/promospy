# Следующему агенту — 0.8.1

Прочитать README.md и docs/release-0.8.1.md. Последнее требование владельца: промокоды автоматически загружаются при открытии магазина; сначала официальный сайт, затем доступные сторонние источники. API-ключей нет. Главная остаётся каталогом. Корзины, вход в аккаунты и Prisma не возвращать.

1. Выполнить pnpm test:live 54 201 без тестового preload, сохранить фактический результат. В этой среде Node не может читать магазины, хотя отдельный веб-инструмент видит опубликованные коды. Проверить живой сбор при локальном запуске в обычном VS Code или на сервере с доступной сетью: ВкусВилл, Магнит, затем остальные по одному. Сохранить фактические HTML-фикстуры. В текущей среде сайты закрыты сетевой политикой; не объявлять моки живым сбором.
2. Проверить дополнительные официальные страницы акций и адаптировать карточки к реальной разметке. Подтверждённая публикация не означает применение в корзине. Не придумывать коды и даты.
3. Сверить приоритет официальных условий, промежуточную выдачу и сохранение старых кодов при сбое конкретного источника.
4. Получить локальный оригинал логотипа Крошки Картошки с указанием источника. Остальные 12 логотипов уже локальные и видимы без JavaScript.
5. Проверить избранное и быстрые переходы в браузере владельца, мобильные касания, reload, разные вкладки и запрет localStorage.
6. Проверить START_WINDOWS.cmd и первый запуск start.py на чистой Windows с Python 3.9+ без Node.js; Linux-загрузчик проверен отдельно. GitHub и Codespaces не должны требоваться.
7. При предоставленном сервере настроить постоянный PROMO_SEARCH_DATA_DIR и резервирование кеша. Не включать старые SQLite backup units для нового кеша.

Текущие проверки: 62 unit-теста, 22 сценария поиска магазинов, 2 браузерных сценария, lint, typecheck и production build. В package.json указан --experimental-test-isolation=none из-за resolver hook в Node 24.22. Проверять реальное число тестов, не только завершение файлов.

После изменений обновить памятку, выполнить затронутые проверки и запушить с коротким осмысленным названием.
