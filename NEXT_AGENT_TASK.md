# Задание следующему агенту — PromoSpy 0.16.0

Репозиторий: https://github.com/Startcpc/promospy, рабочая ветка `main`.
Сначала прочитать `AGENTS.md`, `README.md` и `NEXT_STEPS.md`. В `node_modules/next/dist/docs/` есть документация именно установленной версии Next.js; API error boundary использует `retry`.

## Текущий результат

Приложение работает для одного магазина — ВкусВилл (54). Новый дизайн, фильтры и сортировка; исправления избранного, полных условий, offline и минимальной суммы заказа. Next.js 16.4.5. Устаревшие ветки удалены, PR #1 закрыт; уникальный старый коммит сохранён архивным тегом. `NEXT_STEPS.md` содержит инструкции пользователю и границы проверки.

Проверено: 266 unit-тестов, 25 проверок поиска, 12 тестов лаунчера, 9 сценариев Chromium, lint, typecheck, production build, audit. Docker собран с CA данной среды; не отключать TLS. Кеш переживает пересоздание контейнера. Реальный браузер без mocks: 24 предложения, 9 страниц HTTP 200, clipboard, сохранение, reload/offline. Свидетельства: `docs/live-search-verification.json`, `docs/search-desktop.png`. Это результат 17.11.2026, а не обещание будущей доступности.

## Обязательные свойства

- Первый поиск только по «Обновить»; не показывать старый кеш при открытии/перезагрузке страницы. Затем обновлять каждые 5 минут, пока сервер жив.
- Сохранять условия целиком, регистр кодов, различия кампаний с одинаковым кодом. Не обещать применение в корзине.
- Ошибка отдельного источника не прерывает остальные. Не обходить CAPTCHA, вход, robots.txt и ограничения доступа; не скрывать ошибки под выдуманными результатами.
- Не удалять пользовательские избранное, кеш и бэкапы при очистке. Не возвращать SQLite, Prisma и старые магазины.
- После каждой завершённой задачи — небольшой коммит и push. Пользователь особо просит не держать всю работу только локально.

## Команды

```sh
pnpm install --frozen-lockfile
PROMO_TEST_CHROMIUM_EXECUTABLE=/usr/bin/chromium pnpm check
pnpm test:live 54
# С уже запущенным приложением, без сетевых mocks:
PROMO_TEST_CHROMIUM_EXECUTABLE=/usr/bin/chromium pnpm test:live:ui http://127.0.0.1:3000
pnpm audit --prod
# Из чистого Git-коммита:
pnpm package:zip
```

Для пользовательского запуска: `python3 start.py`; Windows — `START_WINDOWS.cmd`. Интернет для первой установки и поиска обязателен. Результаты дополнительной работы дополнять в `NEXT_STEPS.md`; инструкцию для пользователя не размазывать по новым handoff-файлам.
