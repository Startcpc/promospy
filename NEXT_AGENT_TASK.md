# Следующему агенту — PromoSpy 0.12.0

1. Прочитать AGENTS.md, README.md, CODEX_HANDOFF.md и docs/release-0.12.0.md. Поддерживается только ВкусВилл (54).
2. Сначала воспроизвести дефект. Для сети: `pnpm test:live 54`, `pnpm audit:sources 54`. Сохранить фактические URL, статусы и документы в work/, не подменять их фикстурами.
3. Не возвращать отключённые источники без нового подтверждения публичного доступа. Не угадывать URL, код, дату или условия. GetCashback `.promo-num` читается полностью, рекомендации после `.coupon-title` отсекаются.
4. Отдельный список чужих брендов — только отрицательные признаки принадлежности. Он не должен превращаться обратно в каталог магазинов. Все `/api/scan/:id`, кроме 54, возвращают 404.
5. Не стирать старый localStorage v1, неактивный кеш, SQLite, Prisma или резервные копии. Поддерживать миграцию смешанных backup в ВкусВилл с сохранением исходных данных.
6. После изменений выполнить `PROMO_TEST_CHROMIUM_EXECUTABLE=/usr/bin/chromium pnpm check`, затем проверить настоящую production UI и живой поиск. В итогах разделять управляемые ответы и настоящий интернет. Windows/macOS/Safari без запуска на целевых устройствах не считать проверенными.
