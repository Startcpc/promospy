# Задание следующему агенту

PromoSpy 0.17 ищет опубликованные промокоды для шести магазинов. Для проверки выберите магазин в каталоге и нажмите «Обновить». Ссылки и сроки показаны на карточках. Избранное и его экспорт работают в браузере.

## Следующая задача

Проверьте покрытие официальных страниц у пяти новых брендов. Начните с одного магазина. Найдите публичную страницу акций на его домене и проверьте, опубликован ли там полный код вместе с условиями. Если на странице есть только общая скидка, оставьте её вне списка промокодов. Сохраните адрес, дату чтения и результат проверки. Добавляйте адаптер только для подтверждённой разметки.

## Проверка результата

1. Проверьте правильный магазин, дату окончания и исключение карточек из блоков рекомендаций на небольших тестовых документах.
2. Выполните `pnpm check`, затем `pnpm test:live ID`. Идентификаторы перечислены в `src/lib/companies.ts`.
3. Запустите собранное приложение и выполните `pnpm test:live:ui http://127.0.0.1:3000 ID`. Сравните условия первой карточки с публикацией по ссылке. Сообщите отдельно, если источник недоступен или найдено ноль предложений.
4. Отправляйте каждый завершённый шаг в GitHub. Для GPT Sites используйте действующий проект и проверяйте API поиска на опубликованном адресе. Для передачи проекта соберите ZIP командой `pnpm package:zip` после коммита.
