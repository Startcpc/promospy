Что сделать дальше:

1. Проверить живой поиск в Codespaces/на целевом сервере: доступность RSS Bing и страниц из SEARCH_DOMAINS. Не путать 30 целевых доменов с числом реально прочитанных. Не обходить ограничения сети.
2. Сохранить фактические HTML-фикстуры нескольких доступных купонных сайтов и доработать извлечение строго внутри карточки. Не придумывать коды, даты и подтверждения применения.
3. Проверить клиентское избранное в браузере владельца и Codespaces: сохранение копии, reload, разные вкладки, запрет localStorage и восстановление после очистки серверного кеша.
4. Проверить работу за прокси/Origin. Если Host переписывается, настроить PROMO_PUBLIC_ORIGIN; не отключать проверку чужих источников.

Текущие проверки: 29 unit-тестов плюс один браузерный сценарий, lint, typecheck, production build. Браузерный тест использует настоящий файловый кеш и API приложения, но внешнюю купонную страницу заменяет контролируемая фикстура. Отдельно зафиксировать результат живого поиска, а не приписывать успех моку.
