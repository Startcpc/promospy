Оставшаяся внешняя приёмка:

3. Проверить обычный запуск и backup/restore на физическом Mac с macOS 12 и Safari, затем на Windows с Python 3.9+ без Node в системе. GitHub/Codespaces для запуска не требуются. Проверить импорт файла в другом браузере и работу при запрещённом localStorage.
4. Получить оригинал логотипа Крошки Картошки с источником и сохранить локально. Сейчас внешний логотип имеет текстовый fallback; остальные 12 файлов локальные. Не рисовать замену и не выдавать её за оригинал.
5. При предоставленном сервере применить docs/server-setup.md: постоянный PROMO_SEARCH_DATA_DIR, отдельный PROMO_SEARCH_BACKUP_DIR, service и ежедневный timer. Выполнить реальную проверку восстановления при остановленном сервисе и копирование на внешнее хранилище владельца. Перед восстановлением остановить и сервис, и таймер.
6. Проверить фактическое выполнение GitHub Actions после пуша. Локальный успех pnpm check не называть зелёным результатом удалённого workflow без просмотра запуска.

Проверки 0.9.0: 104 JS-теста на Node 22/24, 22 сценария поиска магазинов, 6 браузерных сценариев, 10 Python-проверок и 2 SQLite-проверки; lint, typecheck, production build. pnpm check включает проверки JS/SQLite/поиска, сборку и браузер; pnpm test:launcher выполняется отдельно. Браузеру требуется установленный Chromium. В CI Python также проверяется отдельно.

python3 start.py --backup создаёт копию текущего JSON-кеша. --restore FILE проверяет копию до замены и сохраняет прежнюю папку. Не менять исходные даты для искусственного продления кеша. Избранное посетителя резервируется файлом со страницы «Избранное», отдельно от серверных результатов. Историческая db/custom.db не изменена.
