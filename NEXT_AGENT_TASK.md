# Следующему агенту

Текущая версия: 0.6.0. Прочитать `docs/release-0.6.0.md`, затем выполнить оставшиеся задачи из `docs/NEXT_AGENT_TEST_PLAN.md` (20 проверок).

## Что сохранять

- Короткий интерфейс: крупный текст, белый/оранжевый/синий ретро-дизайн, анимации с reduced motion. Технические сведения только под раскрытием.
- `official` — публикация, `evidence.cartCheck` — отдельная попытка корзины. Ошибка сети/корзины не стирает последнее подтверждение. Не выдумывать коды, регион и успешный сбор.
- Рабочую SQLite не перезаписывать снимком. Перед изменениями схемы делать backup. Не коммитить .env и зависимости.

## Что проверить дальше

1. Установить штатный движок Prisma, выполнить полный `pnpm test` и `pnpm test:smoke` на отдельной базе. В текущем окружении они заблокированы сетевой политикой; клиент без движка использован только для компиляции.
2. Проверить реальные POST из Codespaces и собственного прокси: публичный Host/Origin, автоматическое определение Codespace, при необходимости PROMO_PUBLIC_ORIGIN. Убедиться, что чужой Origin остаётся запрещённым.
3. Проверить живые перенаправления и чтение ВкусВилла/Магнита, затем заполнение тестовых корзин без входа и оформления заказа.
4. Получить локальный оригинальный файл логотипа Крошки Картошки из проверенного источника. Сейчас используется внешнее изображение из публикации Hi-Tech Mail; оно не заменяет проверенную локальную копию, и в ограниченной сети не загружается. Самодельная иллюстрация удалена.
5. Крошка Картошка: офлайн-купоны не выдавать за коды доставки; онлайн-корзина ещё не подключена. Тануки остаётся заблокированным.
6. При наличии сервера проверить перезапуск, очередь, backup/restore и внешние копии.

Последние проверки: 57 доступных тестов, lint, typecheck, production-сборка и HTTP 200 dev. Браузерные сценарии используют изолированные API, а не живые магазины.

После работы обновить эту памятку, записать фактические результаты и ограничения, запушить с коротким понятным названием коммита.
