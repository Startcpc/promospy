# Сбор официальных акций Тануки: результаты 5 ноября 2026

## Решение

Автономный сбор в проверенном окружении не подтверждён и сейчас заблокирован доступом к источнику. Нельзя считать задачу реализованной или обещать, что перенос на произвольный сервер решит проблему. Невозможность сбора вообще также не доказана: публичные акции доступны в браузере приложения.

## Наблюдения

- Обычный HTTP GET московского меню: 401, страница проверки QRATOR вместо акций.
- Фоновый браузер сборщика: после выполнения JavaScript список акций не загружается.
- Полный Chromium (`channel: chromium`, без подмены браузера, личного профиля или cookies): начальный ответ 401, `/__qrator/qauth.js` — 200, `/__qrator/validate` — 403. На странице явный отказ в доступе; поля меню нет.
- Браузер приложения загружает московское меню и 11 ссылок на акции. NEW20 виден в баннере и в полных условиях акции. Это отдельная сессия, а не доказательство доступности для фонового процесса.
- Публичный скрипт `/static/assets/client-Dpzh1ZdA.js` содержит `getPromos`, читающий `v1/promos` с `brandId` и `cityId`. В публичной конфигурации страницы указан `https://api.tanukifamily.ru/`. Запрос справочника `v1/cities?isWithSeoRegions=1` без авторизации получает HTML 403, а не JSON. Аккаунт для чтения видимых акций не требуется; ошибка возникает на уровне доступа.

## Исправления алгоритма

Прямой запрос `v1/promos` без параметров также вернул HTML 403. Данные акций получить не удалось; проверка с конкретными идентификаторами города и бренда не выполнялась.

1. Начальный HTTP 401 больше не прекращает ожидание обычной загрузки страницы.
2. Поле меню распознаётся по `placeholder`, как на реальном сайте. Ранее поиск по accessible name не находил поле без label/aria-label даже на загруженной странице.
3. Неполное чтение и отказ доступа не считаются исчезновением промокодов. Подтверждённый официальный статус сохраняется, дата наблюдения не обновляется фиктивно.

Тест ожидания загрузки использует реальный формат поля (`placeholder`, без `aria-label`). Проверка: `node --env-file=.env --import ./scripts/register-ts.mjs --test tests/tanuki-navigation.test.ts`.

## Условия дальнейшего запуска

Предпочтительный вариант — согласованный доступ к официальным данным: выгрузка/API или разрешение запросов с адреса сервера. Другой вариант требует отдельного испытания обычного автономного браузера в целевом окружении; результат заранее неизвестен. Перенос личных cookies, ручное копирование и чтение через чат не являются серверной автоматизацией.

Критерий готовности: сборщик самостоятельно получает полный московский список, извлекает условия кодов, повторяет это после перезапуска без участия человека, обновляет базу; при успешном полном снимке снимает официальный статус отсутствующих кодов, а при 401/403/таймауте сохраняет прежние данные. Проверка только известных NEW20/DR15 недостаточна — новые коды должны обнаруживаться из списка акций.

Диагностика текущего сборщика: `node --env-file=.env --import ./scripts/register-ts.mjs scripts/check-tanuki-official.ts`. Ненулевой код завершения и `complete: false` означают, что полный сбор не состоялся.
