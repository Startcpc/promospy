# Сервер PromoSpy

Один долгоживущий Node.js 22.18+ процесс. Выполнить `pnpm install --frozen-lockfile`, `pnpm build`, затем `pnpm start`. Системный браузер, аккаунты, API-ключи и движок Prisma для приложения не нужны.

Задать `PROMO_SEARCH_DATA_DIR` абсолютным путём на постоянном диске, например `/var/lib/promospy/search`. Каталог должен быть доступен на запись пользователю сервиса. По умолчанию данные находятся в `.cache/promo-search` проекта; start.mjs разрешает путь до смены рабочего каталога standalone-сервером.

Сервис `deploy/systemd/promospy.service` и Caddy можно адаптировать к своему серверу. `deploy/promospy.env.example` обновлён под новый поиск. Резервировать новый каталог кеша отдельно; старые SQLite backup unit-файлы удалены.

Кеш состоит из атомарно заменяемых JSON-файлов. При необходимости резервировать этот каталог отдельно. Избранное хранится в браузерах посетителей. `/api/health` проверяет доступность каталога поиска; 200 не гарантирует доступность внешних сайтов.

Исходящему HTTPS нужны Bing для RSS-поиска и домены из `src/lib/web-search.ts`. Если сеть запрещает доступ, приложение показывает ошибку/частичный результат; ограничения сети не обходятся. После перезапуска результаты сохраняются, а незавершённый поиск можно запросить заново.
