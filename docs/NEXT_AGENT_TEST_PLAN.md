# Приёмка следующим агентом — поиск без ключей

Прочитать NEXT_AGENT_TASK.md. Это план дополнительных проверок на целевом сервере, не отчёт о прохождении. Для каждого пункта сохранить фактический результат. Корзины и Prisma в текущий сайт не входят.

1. Установить зависимости через pnpm install --frozen-lockfile на Node 22.18+ (дополнительно — Node 24).
2. Выполнить pnpm lint, pnpm typecheck и pnpm test.
3. Выполнить pnpm test:search для поиска по условиям промокодов.
4. Собрать приложение и выполнить pnpm test:ui с Chromium.
5. Убедиться, что главная не запрашивает API промокодов.
6. Проверить прямую ссылку /company/54, 404 для удалённых ID и возврат на главную.
7. Убедиться, что посещение страницы ВкусВилл запускает поиск автоматически, а предзагрузка ссылки — нет.
8. Проверить автоматический и ручной POST из Codespaces без ошибки Origin.
9. Проверить доступность публичной RSS-выдачи Bing.
10. Сохранить фактическую разметку доступных купонных страниц.
11. Сопоставить извлечённые коды с источником, включая регистр.
12. Проверить привязку предложения к нужному магазину.
13. Проверить условия и даты внутри одной карточки.
14. Сопоставить показанные счётчики с реально прочитанными страницами.
15. Проверить лимит двух поисков, очередь, автоматический кеш и ручное обновление без таймера.
16. Проверить сохранение предыдущей выдачи после сетевой ошибки.
17. Проверить избранное после reload, очистки серверного кеша и в другой вкладке.
18. Проверить запрет localStorage и предупреждение о памяти вкладки.
19. Проверить ширины 320/390/768/1280, клавиатуру и reduced motion.
20. Проверить постоянный каталог кеша, рестарт сервера и восстановление резервной копии.

Моки не подтверждают живой сбор. Недоступность источника зафиксировать явно. Найденный код не объявлять проверенным в корзине. После исправлений обновить памятку и выполнить затронутые проверки.
