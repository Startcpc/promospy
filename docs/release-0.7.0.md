# 0.7.0 — поиск по магазинам

По запросу владельца встроенный ИИ заменён обычным поиском без ключей. Старые официальные сборщики, фоновая очередь, SQLite-доступ приложения и проверки корзин вынесены в `archive/legacy` и не запускаются. Исторический снимок базы сохранён.

Главная показывает только магазины и не делает API-запросов поиска. На странице каждого магазина поиск запускается кнопкой. Целевой набор — 30 доменов: официальный сайт и 29 открытых источников. Публичная RSS-выдача Bing используется для обнаружения страниц; затем читается до 30 страниц с лимитом параллельных запросов и времени. Есть запасные известные адреса, если RSS недоступен. Код извлекается только из явной записи или подписи в карточке; ссылки, условия и регистр сохраняются. Результат не объявляется рабочим или официально подтверждённым.

30 — целевой набор, не число реально успешно прочитанных сайтов. Количество прочитанных/недоступных страниц видно на странице. Неизвестная разметка может дать пустой список. Внешняя блокировка не обходится.

Кеш отдельный для каждого магазина, на диске, с повтором через 15 минут; не больше двух поисков одновременно в одном Node-процессе. Избранное хранит обезличенную копию предложения без подтверждённого статуса. Работает без Prisma и после очистки серверного кеша. При запрете localStorage доступна память вкладки с явным предупреждением.

Кликабельные элементы больше не сдвигаются на hover; движение осталось на декоративных слоях. Карточки магазинов стали обычными ссылками. Фильтр кандидатов теперь «Без истёкших»: он не скрывает все непроверенные находки.

Проверены 29 unit-тестов и браузерный сценарий с реальным новым API, временным файловым кешем и настоящим localStorage: отсутствие запросов на главной, стабильность ссылки, избранное/перезагрузка/удаление, сохранённая копия после очистки кеша, память при запрете хранения, поиск только по нажатию и ширина 320 px. Внешние страницы в unit-тестах изолированы; успешный живой сбор 30 сайтов не заявляется.

Полный lint, typecheck и production-сборка проходят без генерации или заглушки Prisma. Запуск: `pnpm install --frozen-lockfile`, затем `pnpm dev`. Старый .env можно сохранить; ненужные переменные игнорируются. Для нового сервера задайте постоянный PROMO_SEARCH_DATA_DIR. Старые SQLite backup unit-файлы не резервируют новый кеш.

Отдельно прошли 22 сценария поиска магазинов (`pnpm test:search`): исправлено устаревшее ожидание 12 компаний вместо 13 после добавления Крошки Картошки. Браузерный тест явно ждёт перехода в избранное перед перезагрузкой, чтобы не проверять предыдущую страницу из-за гонки навигации.

Живой пробный запуск ВкусВилла из текущего окружения завершился ошибкой «Открытые сайты недоступны»: успешный внешний сбор не подтверждён. Это не ограничение ключа — ключи не используются.
