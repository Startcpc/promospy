# PromoSpy 0.12.0 — только ВкусВилл

Дата проверки: 9 ноября 2026 года. База изменений — `c53d9d83a9e8a46b286561e73208b3f353166971`. Next.js 16 / React 19 / TypeScript / pnpm сохранены; движок кеша обновлён с 6 до 7.

## Реализация и подтверждённые дефекты

- Единственный активный магазин — ВкусВилл, ID 54. Удалены остальные записи, алиасы поиска, адаптер Магнита, категории, выбор магазинов, 11 ненужных логотипов и устаревшие проверки выбора магазинов. Главная сохраняет оранжево-синюю графику PromoSpy и ведёт к предложениям ВкусВилл. Удалённые ID возвращают 404 в scan API и страницу отсутствующего ресурса в UI.
- Чужие бренды распознаются как отрицательные признаки принадлежности независимо от активного каталога. Рекомендации, фиды, вложенные merchant records и официальные страницы с чужим заголовком покрыты регрессиями.
- Воспроизведено превращение «Промокод: нет», `undefined` и «HTTP 403» в коды. Заглушки теперь отвергаются при извлечении, чтении кеша и избранного.
- Воспроизведено усечение `ABC***`, `ABC…`, `ABC...`, `ABC•••` и `ABCD/1234` до вымышленного полного кода. Текстовый парсер сначала читает весь токен и затем проверяет его. Обычная пунктуация после полного кода допустима; регистр сохраняется.
- Настоящий production-поиск обнаружил смешение текущей официальной акции «1раз» с архивной карточкой GetCashback: срок 31 декабря 2025 года из каталога попадал в текущую официальную запись без срока. Теперь завершённая и текущая кампании не объединяются даже при одинаковой строке кода и сумме. Регрессия проверяет оба порядка объединения. После исправления официальный код остаётся видимым, архив хранится отдельно.
- Воспроизведён пропуск URL `/%61ccount/` фильтром публичных путей. Проверяется декодированный путь; кодированные разделители и некорректные percent escapes также покрыты тестами. HTTPS, публичные IP, закрепление DNS при прямом соединении, host allowlist, Origin и лимиты не отключались.
- В настоящем браузере воспроизведена ошибка 404 при запросе отсутствующего favicon. Добавлен SVG-значок PromoSpy и metadata, проверяемые UI-тестом. Повторный браузерный прогон не содержит этой ошибки.
- На настоящей странице Promokod.com атрибут полного кода расположен во внешней обёртке, а условия — рядом с внутренней `.coupon`. Раньше заголовок захватывал всю обёртку, включая «Проверено», счётчики использования и активность посетителей. Адаптер сохраняет явный код, название, сумму скидки, условия и срок, исключая чужие merchant owners и эти неподтверждённые checkout-утверждения. Исправлено чтение `data-title` как атрибута, а не текста контейнера.
- Дубликаты ID из дискового кеша объединяются перед рендерингом; повреждённый кеш не подавляет обновление. Размер файла проверяется до чтения. Сохранённые при частичном обновлении предложения помечаются отдельно. Состояние поиска явно отвергает неподдерживаемые ID.

HTTP-клиент с ограниченными повторами, Retry-After, очередью, circuit breaker и проверкой robots сохранён и проверен. Один источник не прерывает весь поиск. Непонятная разметка не выдаётся за отсутствие кодов. Есть проверки 400/401/403/404/408/429/500/502/503/504, таймаутов, TLS, DNS, сбросов соединения, CAPTCHA, перенаправлений, некорректных документов, отмены и параллельных запросов.

## Данные

Старый localStorage `promospy:saved-promos:v1` остаётся без изменений. Читаются только записи ВкусВилл, изменения сохраняются отдельно в `promospy:saved-promos:vkusvill:v2`. Проверены сохранение после reload, межвкладочная синхронизация, запрещённое хранилище, экспорт/импорт и миграция смешанного списка. Старые непривязанные к магазину ID мигрируются в ID ВкусВилл с сохранением снимка и времени. Противоречащие ID и значения кода отвергаются.

Регрессионным файловым тестом воспроизведено удаление старой многомагазинной копии при ротации новых одномагазинных backup. Ротация теперь ограничивается семью исправными копиями только ВкусВилл; исторические многомагазинные и повреждённые копии не удаляются. Восстановление многомагазинной копии активирует только ВкусВилл. Полный исходный файл и прежняя папка остаются для восстановления. Неактивные файлы кеша не удаляются. `db/custom.db` и `prisma/schema.prisma` не изменены; активный поиск не использует исторический SQLite. Синтетические тестовые коды не записаны в рабочие данные и не поставляются как результаты поиска.

Официальные карты сайта и прямые каталоги работают независимо от этих индексов. Две прочитанные официальные страницы акций без извлекаемых кодов честно обозначены как нераспознанные, без вымышленных предложений.

Сырые документы, robots, конечные URL и отчёты сохранены в игнорируемой `work/`; эти наблюдения не гарантируют будущую доступность.

## Границы

Коды найдены в публикациях, а не проверены применением в корзине. Условия источников могут измениться; часть предложений не содержит точного срока. Заблокированные страницы не обходятся. Обязательная стоимость приложения — $0; модели и AI API не требуются.

Поддерживается один Node-процесс с постоянным диском. Cooldown источников и объединение запросов действуют внутри процесса; распределённая координация нескольких реплик не реализована. Нативные Windows, macOS, Safari и физические мобильные устройства в этой сессии не запускались. Проверен Chromium с разными viewport.
