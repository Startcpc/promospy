# 0.6.0 — ретро-дизайн и обновление

- Убраны длинная инструкция на главной и повторяющиеся мелкие подписи. Даты, ошибки источника и журнал собраны под «Подробнее об обновлении».
- Белый фон, синие буквы, оранжевые акценты, печатные рамки и тени. Буквы появляются по очереди и двигаются при наведении; карточки приподнимаются. `prefers-reduced-motion` отключает движение.
- Индикатор Next.js выключен настройкой `devIndicators: false`. Dev запускается через Webpack.
- Исправлен отказ Origin при корректном публичном Host за прокси. Codespaces определяется по переменным окружения; для другого прокси предусмотрен `PROMO_PUBLIC_ORIGIN`. Чужие и некорректные Origin по-прежнему отвергаются. Произвольный X-Forwarded-Host не используется как разрешение.
- Официальный сборщик следует HTTP-перенаправлениям только внутри официального хоста (включая www); цепочка ограничена четырьмя запросами. Внешние перенаправления и циклы дают ошибку без снятия прежнего подтверждения.
- Самодельная картошка удалена. Для компании подключено изображение бренда из публикации Hi-Tech Mail: https://hi-tech.mail.ru/review/102554-raskryt-sekret-ogromnoj-kartoshki-iz-kroshki-kartoshki/ . URL картинки записан в companies.ts. **Это внешняя картинка, локальная копия не получена:** прямое скачивание недоступно в окружении. Доступность загрузки в браузере владельца ещё нужно проверить. При загрузке или сбое показывается инициал вместо сломанной картинки.

Проверки: 57 доступных тестов прошли (53 в объединённом запуске и 4 проверки официальной разметки), включая hover букв, reduced motion, компактный блок обновления, поиск, избранное, Origin и перенаправления. ESLint, TypeScript и production-сборка прошли. Dev на Webpack вернул HTTP 200.

API в браузерных тестах изолирован. Нативная Prisma, реальные корзины и прямое чтение магазинов требуют отдельной проверки в окружении с доступом; это обновление не является отчётом об их живом успехе.
